# Orqa Admin Dashboard

A responsive admin dashboard built with React, TypeScript, and Vite.

This project demonstrates:

- authentication flow
- protected routing
- responsive dashboard layout
- user management CRUD operations
- reusable UI components
- error handling
- loading states
- toast notifications
- mobile-first responsive behavior

---

## Tech Stack

- React
- TypeScript
- Vite
- React Router
- Context API
- Plain CSS
- Local component state + reducers

---

## Features

### Authentication

- Mock login flow
- Protected routes
- Public route guards
- Auth persistence using localStorage

### Dashboard

- Statistics overview cards
- Recent activity section
- Error simulation + Error Boundary

### User Management

- Create user
- Edit user
- Delete user
- Search users
- Filter by role
- Responsive mobile card layout

### Profile Settings

- Editable profile information
- Preference toggles
- Simulated async save
- Success feedback

### UX Improvements

- Toast notifications
- Loading spinner
- Custom modals
- Responsive sidebar drawer
- Mobile navigation improvements

---

## Error Handling

The application includes:

- reusable Error Boundary
- simulated dashboard error state
- graceful fallback UI
- recovery actions

---

## Getting Started

### Clone repository

### Install dependencies

```bash
npm install
```

### Start development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```
